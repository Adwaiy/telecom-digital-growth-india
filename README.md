# Impact of Telecom Connectivity on Digital Economic Growth in India

State-wise data science and econometric analysis of telecom infrastructure and digital economic participation across Indian states.

## Project Overview

This project investigates whether telecom connectivity drives digital economic growth in India using:

- Telecom infrastructure data
- 5G penetration metrics
- Literacy rates
- GSDP data
- Electronic transaction volumes

The analysis combines:

- Linear Regression
- Elastic Net
- Random Forest
- XGBoost
- K-Means Clustering
- Econometric interaction analysis

## Key Findings

- Literacy was the strongest predictor of digital economic activity.
- Telecom infrastructure alone was insufficient.
- Human capital and digital readiness significantly amplified infrastructure effectiveness.
- XGBoost achieved the strongest cross-validated performance.
